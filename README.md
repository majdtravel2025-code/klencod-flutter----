# تطبيق مطاعم مدينتي

تطبيق طلبات كامل لمطاعم مدينتي: واجهة للزبون، ولوحة للمدير تستقبل الطلبات لحظياً، وخادم Node.js **بدون أي اعتماديات خارجية** (لا تحتاج `npm install`).

## ما الذي يعمل
- **الزبون:** يتصفح القائمة ويضيف للسلة، وعند فتح السلة يُطلب منه تسجيل الدخول أو إنشاء حساب (رقم الجوال + كلمة مرور). بعدها يرسل الطلب ويتابع حالته من «طلباتي».
- **المدير:** حساب خاص يدخل من `/manager`، يستقبل الطلبات لحظياً مع تنبيه صوتي، ويغيّر الحالة (قبول، جاهز، خرج للتوصيل، تم التسليم، رفض). ويعدّل القائمة والأسعار والأقسام، ويوقف صنفاً مؤقتاً، ويفتح/يغلق استقبال الطلبات، ويغيّر كلمة مروره.
- كلمات المرور مشفّرة (scrypt)، والجلسات رموز موقّعة، والأسعار تُحسب في الخادم ولا يُوثق بما يرسله المتصفح.

## التشغيل
يلزم Node.js 18 أو أحدث.

```bash
node server/server.js
# أو
npm start
```

ثم افتح:
- تطبيق الزبون: `http://localhost:3000`
- لوحة المدير: `http://localhost:3000/manager`

عند أول تشغيل يُنشأ حساب المدير ويُطبع اسم الدخول وكلمة المرور في الشاشة. لتحديدهما بنفسك:

```bash
MANAGER_USER=admin MANAGER_PASS=كلمة-مرور-قوية node server/server.js
```

نسيت كلمة مرور المدير؟

```bash
node server/scripts/set-manager.js كلمة-المرور-الجديدة
```

## الملفات
```
server/
  server.js            تشغيل الخادم وإنشاء حساب المدير
  routes.js            كل مسارات الـ API (دخول، طلبات، قائمة، إعدادات)
  config.js            الإعدادات من متغيرات البيئة
  lib/store.js         حفظ البيانات في data/db.json
  lib/auth.js          تشفير كلمات المرور وتوقيع الجلسات
  lib/http.js          قراءة الطلبات وتقديم الملفات الثابتة
  lib/sse.js           بث الطلبات الجديدة للمدير
  scripts/set-manager.js
public/
  index.html           تطبيق الزبون
  manager.html         لوحة المدير
  data/menu.json       القائمة الابتدائية (أمثلة)
  css/                 base, customer, manager
  js/                  config, api, demo, cart, ui, icons
  js/views/            شاشات الزبون
  js/manager/          تبويبات المدير
  assets/              الشعار والأيقونات
  manifest.webmanifest, sw.js   لتثبيته على الجوال كتطبيق
```

## إدخال قائمة المطعم الفعلية
القائمة الحالية **أمثلة** مبنية على أقسام القائمة المطبوعة. أسهل طريقة: ادخل لوحة المدير ← تبويب «القائمة»، وعدّل الأسماء والأسعار وأضف الأصناف. أو عدّل `public/data/menu.json` قبل أول تشغيل.

## النشر على الإنترنت
ارفع المجلد كاملاً إلى أي استضافة تشغّل Node.js (VPS، Render، Railway، Fly.io) وشغّل `node server/server.js`. وانتبه إلى:
1. اجعل `DATA_DIR` على قرص دائم، وإلا تضيع الطلبات عند إعادة تشغيل الاستضافة.
2. فعّل HTTPS (تفعله أغلب الاستضافات تلقائياً)، فكلمات المرور تمر عبر الشبكة.
3. خذ نسخة احتياطية دورية من `data/db.json`.
4. شغّل نسخة واحدة فقط من الخادم، لأن الحفظ في ملف واحد. للتوسع لاحقاً تُنقل البيانات إلى قاعدة بيانات.

## الوضع التجريبي
إذا فُتحت الواجهة من استضافة ثابتة بلا خادم، تنتقل تلقائياً إلى نسخة تجريبية تحفظ البيانات في المتصفح (حساب المدير التجريبي `manager` / `manager123`). هذه للمعاينة فقط. لفرض الوضع الحقيقي غيّر `mode` إلى `'live'` في `public/js/config.js`.

## ما ليس مضافاً بعد
- الإشعار على واتساب أو SMS عند وصول طلب (تنبيه لوحة المدير فقط، لذلك اترك اللوحة مفتوحة على جهاز المطعم).
- الدفع الإلكتروني.
- استعادة كلمة مرور الزبون (يتم يدوياً حالياً).
